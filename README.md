## What this is
The tired person's guide to the AWS Cloud Practitioner (CLF-C02) exam: a 17-page field manual built on the Neuroplasticize™ method — encode by day, consolidate by night™. Plain language, patterns, and why before what — built for understanding, not rote drilling, and made for non-rote learners first.

## The method — Neuroplasticize™
The method this manual is built on. Encode by day, consolidate by night™: spaced review, plain language, and real sleep. Sleep is studying too™.

## Find your style first
The manual opens with the five ways a brain can store information — visual, auditory, read/write, kinesthetic, spatial (memory palace) — and a sixty-second test that locks in which one is yours. Find yourself in one; blends are welcome; the whole system adapts to your letter.
